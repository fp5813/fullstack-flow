# fullstack-flow 流程审计 v2.0.0

**技能路径**: `fullstack-flow/audit-flow`  
**用途**: 标准化全量审核 fullstack-flow 流程 + 项目配置，低风险自动修复。支持用户级（多项目批量审计）和项目级（单项目审计）。

## 快速参考

| 级别 | 范围 | 自动修复 |
|:----:|------|:--------:|
| 项目级 | 当前项目 | ✅ |
| **用户级** | **遍历所有受信任项目** | ❌ 只报告 |

> 触发: 对话中输入 `/fullstack-flow/audit-flow`

## 触发方式

- 对话中输入 `/fullstack-flow/audit-flow`
- 描述"审核 fullstack-flow" 或 "审计流程"

## 执行级别

| 级别 | 触发条件 | 审计范围 | 自动修复 |
|:----:|---------|---------|:--------:|
| 项目级 | 在项目目录下执行 | 当前项目的 fullstack-flow 配置 | ✅ 允许 |
| **用户级** | 在用户根目录下执行 | **遍历所有受信任项目** | ❌ 只报告 |

## 审计内容（20+ 项）

| 维度 | 检查内容 | 适用级别 |
|------|---------|:--------:|
| 注册完整性 | Phase/子技能/References 全部注册到 SKILL.md | 技能级 |
| 引用一致性 | 跨文件引用路径有效 | 技能级 |
| 无硬编码 | 无旧项目路径/本地绝对路径 | 技能级 |
| MCP 一致性 | 服务名与实际配置一致 | 项目级 |
| 状态一致性 | state.yaml 与 schema 一致 | 项目级 |
| 文档完整性 | 7 个 INDEX + TEMPLATE + 决策日志 + metrics 索引 | 项目级 |
| 版本一致性 | version 格式和 CHANGELOG 覆盖 | 技能级 |
| **多项目横向** | **各项目版本/状态/文档横向对比** | **用户级** |

## 输出

- 标准审计报告（8 维度表格 + 多项目横向对比表）
- 自动修复记录
- 改进追踪追加到 `proccess_improvements.yaml`
